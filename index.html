Mise en page

Définitions avancées (JSON)

Clés : links (types de liens : label, arrow, Color, thickness, dashpattern), status, bubbles (SVG + label), emphasis (règles d'emphase des libellés), mandatoryDefs (undef, placeholder, eff, grad), utf8replacement (remplacements dans l'effectivité). L'import accepte aussi un settings.json de VS Code contenant des clés bomarkdown.*.

Bibliothèque d'icônes

Déposez des images ici ou cliquez pour en choisir (PNG, JPG, SVG, WebP).
Le nom du type = nom du fichier en minuscules, sans espaces. Un fichier de même nom met l'icône à jour. Les images sont réduites à 64 px et intégrées en base64.

Aide : syntaxe BoMarkdown

Hiérarchie

Chaque ligne + est un élément ; le nombre de caractères avant le + donne le niveau. Les autres lignes sont ignorées (commentaires).

+ Racine
 + Enfant
  + Petit-enfant
+newcolumn 40      ← nouvelle colonne (+ écart)
+ Autre racine

Blocs d'un élément

BlocRôle
(i:type,libellé,rév)Type (icône), libellé, révision. 1 valeur = libellé seul.
(s:IW)Statut (D, IW, F, R, O…)
(a:alias)Alias, cible des liens transverses
(l:i:a1,a2)Liens de type i vers les alias a1, a2. a1!texte ajoute une étiquette (!< au début, !> à la fin).
(b:lock,matrice)Bulles dessinées sur l'icône
(e:[A -> B[)Effectivité à gauche ; (e:o) = pastille

Emphase dans les libellés : *italique*, **gras**, ***les deux***. Le texte après le dernier bloc est ignoré.

Paramètres par bloc

En tête de bloc, un JSON entre ${{ et }}$ surcharge les réglages (ex. "haslegend": false, "bend": 0.5, "h": 24, "emphasis": […]).

Dans un document Markdown

```bomarkdown images/mon-bom
+ (i:assembly,Produit)
```
<!--bomarkdown images/bom-cache
+ (i:assembly,Bloc non affiché)
-->

Le chemin après bomarkdown nomme le SVG exporté. Placez le curseur dans un bloc pour l'afficher ; Exporter → Insérer les liens image ajoute ![nom](nom.svg) sous chaque bloc.
