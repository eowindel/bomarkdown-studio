Hiérarchie

Chaque ligne + est un élément ; le nombre de caractères avant le + donne le niveau. Les autres lignes sont ignorées (commentaires).

+ Racine
 + Enfant
  + Petit-enfant
+newcolumn 40      ← nouvelle colonne (+ écart)
+ Autre racine

Blocs d'un élément

BlocRôle
(i:type,libellé,rév)Type (icône), libellé, révision. 1 valeur = libellé seul.
(s:IW)Statut (D, IW, F, R, O…)
(a:alias)Alias, cible des liens transverses
(l:i:a1,a2)Liens de type i vers les alias a1, a2. a1!texte ajoute une étiquette (!< au début, !> à la fin).
(b:lock,matrice)Bulles dessinées sur l'icône
(e:[A -> B[)Effectivité à gauche ; (e:o) = pastille
(h:code)Style du lien vers le parent, choisi parmi les styles de hiérarchie (Réglages → Types de liens) : o optionnel, v variante… Affiché dans la légende dès que plusieurs styles sont utilisés.

Emphase dans les libellés : *italique*, **gras**, ***les deux***. Le texte après le dernier bloc est ignoré.

Paramètres par bloc

En tête de bloc, un JSON entre ${{ et }}$ surcharge les réglages (ex. "haslegend": false, "bend": 0.5, "h": 24, "emphasis": […]).

Dans un document Markdown

```bomarkdown images/mon-bom
+ (i:assembly,Produit)
```
<!--bomarkdown images/bom-cache
+ (i:assembly,Bloc non affiché)
-->

Le chemin après bomarkdown nomme le SVG exporté. Placez le curseur dans un bloc pour l'afficher ; Exporter → Insérer les liens image ajoute ![nom](nom.svg) sous chaque bloc.

Hierarchy

Each + line is an item; the number of characters before the + gives its level. Other lines are ignored (comments).

+ Root
 + Child
  + Grandchild
+newcolumn 40      ← new column (+ gap)
+ Another root

Item blocks

BlockPurpose
(i:type,label,rev)Type (icon), label, revision. A single value = label only.
(s:IW)Status (D, IW, F, R, O…)
(a:alias)Alias, target of cross links
(l:i:a1,a2)Links of type i to aliases a1, a2. a1!text adds a label (!< at the start, !> at the end).
(b:lock,matrice)Bubbles drawn on the icon
(e:[A -> B[)Effectivity on the left; (e:o) = dot
(h:code)Style of the link to the parent, picked from the hierarchy styles (Settings → Link types): o optional, v variant… Shown in the legend as soon as several styles are used.

Emphasis in labels: *italic*, **bold**, ***both***. Text after the last block is ignored.

Per-block parameters

At the top of a block, JSON between ${{ and }}$ overrides the settings (e.g. "haslegend": false, "bend": 0.5, "h": 24, "emphasis": […]).

In a Markdown document

```bomarkdown images/my-bom
+ (i:assembly,Product)
```
<!--bomarkdown images/hidden-bom
+ (i:assembly,Block not displayed)
-->

The path after bomarkdown names the exported SVG. Put the cursor in a block to display it; Export → Insert image links adds ![name](name.svg) below each block.
